Software

My research and development work has resulted in various software packages, primarily focused on bioinformatics and data visualisation.

iSEE Ecosystem

The iSEE (Interactive SummarizedExperiment Explorer) ecosystem provides a framework for interactive visualisation of genomics data.

I have collaboratively developed and maintain the core iSEE package along with several extension packages in the Bioconductor project.

iSEE

Core framework for interactive visualisation of genomics data.


iSEEindex

Portal for multiple data sets in a single interface.


iSEEde

Differential expression visualisation panels.


iSEEpathways

Pathway analysis visualisation panels.


iSEEhex

Panels specialised in hexagonal binning.


iSEEhub

Portal for the Bioconductor ExperimentHub data resources.


iSEEu

The “iSEE universe”. Goal: a wrapper for all iSEE extensions, like the tidyverse. For now, a collection of miscellaneous panels and “modes”.


For more information and links to third-party extensions, please visit the iSEE website.
