Bioconductor Ecosystem Development

iSEE Framework for Interactive Visualisation

Development of the Interactive SummarizedExperiment Explorer (iSEE) ecosystem for interactive exploration of genomics data in R/Bioconductor. This includes the core framework and multiple extension packages enabling specialised visualisation capabilities.

Status: Active
Period: 2017–Present
Impact: Widely adopted tool in single-cell genomics community
Collaborators: Charlotte Soneson, Federico Marini, Aaron Lun
